# Тестирование поиска на сайте Самокат

## О проекте
Исследовательское тестирование функции поиска на сайте [samokat.ru](https://samokat.ru).
**Цель:** проверить корректность обработки невалидных запросов (спецсимволов, случайных наборов букв) и выявить дефекты в логике выдачи результатов.

## Методология
В ходе тестирования применялись техники эквивалентного разделения и граничных значений. Проверялись спецсимволы, SQL-инъекции, кириллица и латиница.

## Найденные дефекты

### 🐞 BUG-01: Поиск по невалидным символам показывает товары вместо «Ничего не найдено»
**Severity:** Minor  
**Priority:** Low  

**Суть бага:** При вводе в поле поиска невалидных символов приложение выдает непредсказуемый результат — от случайных категорий товаров (овощи, мясо, косметика) до конкретных продуктов. Хотя должно быть сообщение «Ничего не найдено».

**Шаги воспроизведения:**
1. Открыть приложение Самокат.
2. Перейти в поле поиска.
3. Ввести `!@#$%^&*` и нажать «Найти».
4. Ввести `dd'd'@`, `['d'@` и другие комбинации.

**Ожидаемый результат:** Во всех случаях — сообщение «Ничего не найдено».
**Фактический результат:** Поиск выдает реальные товары (таблица ниже).

| Запрос | Что показывает |
|---|---|
| `!@#$%^&*` | Все товары подряд (попкорн, крекеры, ириски) |
| `dd'd'@` | Овощи (шампиньоны, шпинат, паштет, морковь, грибы, редис) |
| `gg'd'@` | Мясо (варёная колбаса, сосиски) |
| `['d'@` | Косметика (скрабы, шампуни, маски) |

**Влияние:** Непредсказуемое поведение поиска. Пользователь вводит мусор и получает реальные товары, что может привести к покупке не того товара и подрывает доверие к поиску.

---

## Дополнительные наблюдения (исследование)
- **Пустой запрос** → «Ничего не найдено» (правильно).
- **Пробелы** → «Ничего не найдено» (правильно).
- **`!молоко`** → находит молоко (правильно).
- **SQL-инъекции (`' OR '1'='1`)** → «Ничего не найдено» (правильно).
- **Кириллица (`шш'd'@`)** → всегда одно и то же (каши, кофе).
- **Латиница** — результат зависит от символов и длины.
